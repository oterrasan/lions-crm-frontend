# 🚀 LIONS CRM - DEPLOY NO VERCEL

## 📋 INSTRUÇÕES PARA O ROBERTO:

### PASSO 1 - CRIAR CONTA NO VERCEL (GRÁTIS)

1. Acesse: https://vercel.com
2. Clique em "Sign Up"
3. Entre com sua conta do GitHub (ou crie uma)
4. Confirme seu email

---

### PASSO 2 - FAZER DEPLOY

**OPÇÃO A - Pelo Site (Mais Fácil):**

1. Entre no Vercel: https://vercel.com
2. Clique em "Add New Project"
3. Clique em "Browse" ou arraste a pasta `lions-crm`
4. Clique em "Deploy"
5. PRONTO! Em 1 minuto está no ar!

**OPÇÃO B - Pelo GitHub:**

1. Suba a pasta `lions-crm` no GitHub
2. No Vercel, conecte seu repositório
3. Clique em "Deploy"
4. PRONTO!

---

### PASSO 3 - ACESSAR O SISTEMA

Após o deploy, você vai receber um link tipo:

```
https://lions-crm.vercel.app
```

Ou:

```
https://lions-crm-roberto.vercel.app
```
